# Alex Lohinov — Personal website

React, TypeScript, Vite, and plain CSS. Recreated from the Figma frame `13:33` in `My Personal Website`. Inter is bundled locally; images are the original Figma exports.

## Development

```sh
nvm use
npm ci
npm run dev
```

## Validation and production

```sh
npm run typecheck
npm test
npm run preview
```

Use Node.js 24 (pinned in `.nvmrc`). `npm test` builds the site and checks the served HTML, metadata, PNG cards, crawler files, legacy links, and HTTP 404 responses. `npm run build` builds without running the tests. Both npm and pnpm lockfiles are maintained; the Vercel configuration explicitly uses npm.

The production output is in `dist/`. The build renders the React pages to HTML, then hydrates them in the browser. `vercel.json` serves clean URLs without trailing slashes and lets Vercel serve `404.html` with HTTP 404 for missing pages. No catch-all rewrite to the homepage is needed. On another host, configure extensionless HTML routes and use `404.html` as the error document while preserving the 404 status.

## Content and links

Edit `src/content.ts` to configure social destinations and the `href` fields for work, experience, and writings. The supplied LinkedIn, GitHub, X, and email destinations are connected. Unpublished Wren is a non-focusable span marked `aria-disabled`, without an arrow or hover action. Working links and Email on the homepage highlight their row while other content dims. Adding an `href` turns an entry into a working link.

Social and company links open in a new tab. The Accord entry opens a CRM design case study at `/work/accord`, organized as Problem, Reasoning, Decisions, Solution, and Impact. It describes design decisions and intended benefits without claiming measured outcomes. Its six original WebP images live in `public/images/accord/` and open at full size in new tabs. How I Use Codex opens at `/writings/how-i-use-codex`, with article content in `src/CodexArticle.tsx`.

Accord uses the optional wide reading layout: 520 px text, images up to 960 px, and a left-hand line navigation from 1480 px. Old Accord section anchors map to the corresponding new sections. All reading pages share `src/ReadingLayout.tsx`, with a nested table of contents, the current section highlighted while scrolling, and a collapsible contents list on smaller screens. Section links use native anchors, such as `/writings/how-i-use-codex#codex-app`. Keep the table of contents and heading IDs in sync when editing sections. Existing `/#/…?section=…` links redirect to the new URLs in `src/legacy.ts`.

## SEO and social previews

`src/site.ts` is the central configuration for the canonical origin (`https://lohinov.com`), public routes, page titles, descriptions, and OG images. Metadata is present in the initial HTML, including Open Graph and Twitter large-image cards. The 404 has `noindex` and no canonical tag. Article pages use semantic `main`, `article`, `header`, `section`, `nav`, `figure`, and `footer` elements; a skip link supports keyboard navigation.

`scripts/build.mjs` generates `sitemap.xml`, `robots.txt`, and identical `llm.txt` / `llms.txt` files in `dist/`. Only published public routes enter the sitemap. The LLM files provide a readable index; they do not guarantee indexing or control model training.

OG cards are checked-in 1200 × 630 PNG files under `public/og/`. Their editable SVG masters are generated by `npm run og:source` from `scripts/generate-og.mjs`. After changing a master, export it to the matching PNG at 1200 × 630 (for example, capture its local browser URL at that viewport). The build uses the PNG files, so social crawlers do not need SVG support or JavaScript.

## Beach footer

`src/BeachFooter.tsx` mounts a decorative canvas only in the shared site footer. `src/beachScene.ts` draws an original pixel-grid shoreline, dunes, grass, sun, and gulls without image assets or animation dependencies. Waves and grass animate at up to 24 frames per second; rendering pauses when the footer is offscreen or the browser tab is hidden. The illustration adapts to screen size and color scheme, shows a static scene with reduced-motion preferences. There is no manual pause control.

## Analytics

`@vercel/analytics` and `@vercel/speed-insights` are mounted once in `src/Root.tsx` using their React integrations. Speed Insights receives the current page route. Local browser checks verify script integration; real visitor metrics require a Vercel deployment and must be checked in the project's Speed Insights dashboard. Local preview does not serve Vercel's collection endpoints.

## Pascal and reading navigation

Pascal is available at `/work/pascal` as **A Quiet Space to Think**. It presents a local note-taking app design, with five sections and five original WebP images. It makes no claims about shipped functionality or measured outcomes. Accord and Pascal share `CaseImage` and the wide reading layout.

Desktop reading navigation is a left-hand line rail that reveals the contents on hover or button activation. Escape and section selection close it. On smaller screens (below 1480 px for cases, below 1121 px for the article) and devices without hover, it becomes a collapsible contents list above the text. Current-section highlighting and existing Accord anchors are retained.
